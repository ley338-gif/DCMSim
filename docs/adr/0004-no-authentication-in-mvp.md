# ADR-0004: No authentication in MVP

**Status:** Accepted

**Context:** Der MVP läuft als lokales internes Einzelwerkzeug.

**Decision:** Es gibt keine Benutzerverwaltung oder Authentifizierung.

**Consequences:** Kleiner, wartbarer Stack. Betreiber dürfen DCMSim nur in vertrauenswürdigen Netzen bereitstellen; öffentlicher Betrieb ist ausgeschlossen.
